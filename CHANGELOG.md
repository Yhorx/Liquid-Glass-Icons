# Changelog

All notable changes to the **Liquid Glass Dark** Icon Theme project are documented in this file.

## [1.0.0] - 2026-11-11

### Added
- **Liquid Glass Application Icons**: Over 300+ application squircles rendered in authentic macOS Liquid Glass dark style.
- **Normalized Squircle Geometry**: Custom 81.25% canvas proportion (416px content on 512px canvas) preventing oversized dock and app finder icons.
- **macOS Tahoe Directory Folders**: Beautiful rounded sky-blue directory icons with debossed monochrome emblems for Downloads, Documents, Pictures, Music, Videos, Desktop, Home, Templates, and Public.
- **Full Top Panel Integration**: Authentic macOS dark menu bar status icons (PulseAudio speaker with 3 waves, WiFi signal arcs from 0% to 100%, battery capsule with lightning bolt, Bluetooth runes, session shutdown/reboot actions).
- **Custom macOS Night Shift Indicator**: Designed radiant warm amber sun for active Redshift mode and delicate outline sun for inactive mode.
- **Desktop Docklet & Show Desktop**: Native Tahoe screen folder and iMac display icons for Plank docklet desktop and XFCE showdesktop plugins.
- **Thunderbird Integration Fix**: Cleaned `.desktop` specification with `StartupWMClass=Mail` preventing duplicate running instances on Linux docks.
- **Cross-Desktop Support**: Full compatibility with GNOME Shell, XFCE, KDE Plasma 5/6, Cinnamon, MATE, Budgie, and LXQt.
- **Automated Installer & Uninstaller**: Multi-platform `install.sh` supporting user (`~/.local/share/icons`) and system-wide (`/usr/share/icons`) installations.
